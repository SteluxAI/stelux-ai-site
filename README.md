# Stelux AI — production website

Dark, depth-driven marketing site for [stelux.ai](https://stelux.ai): a fora.so-style dusk hero (sky shader, rolling hills behind an orchestration dashboard, foliage in front) with 3-layer parallax (0.3x / 1.0x / 1.4x), the existing Stelux products, fora-style stacking feature cards, an interactive CLI/SDK showcase, live-feel telemetry, an access matrix and a minimalist footer.

**Stack:** Vite 6 · Tailwind CSS v4 · GSAP ScrollTrigger · Lenis · Playwright (visual audit) · static output in `dist/`.

## Scripts

| Command | What it does |
| --- | --- |
| `pnpm dev` | Dev server on http://localhost:5173 |
| `pnpm build` | Production build → `dist/` (relative asset paths, works at any base URL) |
| `pnpm preview` | Serve `dist/` on http://localhost:4173 |
| `pnpm shots` | Screenshot + audit loop: 1440px and 375px at 0/25/50/75/100% scroll. Flags horizontal overflow, clipped text and text collisions. Output in `shots/` (`SHOT_URL`, `SHOT_DIR`, `SHOT_DEPTHS` env overrides) |
| `node scripts/og.mjs` | Re-render `public/og.png` from the live hero |
| `pnpm deploy` | `wrangler pages deploy dist` to the Cloudflare Pages project `stelux-ai` (needs `npx wrangler login` or `CLOUDFLARE_API_TOKEN`) |

## Hero assets

The six hero layers live in `public/img/hero-v4/` (desktop 2172×724, mobile 1448×1086, WebP with alpha) and were generated outside this repo; their masters, manifest and the foreground alpha profile come from the `output/hero-assets-v4/` handoff (git-ignored). `src/data/hero-foreground-profiles.json` is bundled so the panel's scroll lag is capped 24px clear of the CTA. Replace a layer by dropping a new WebP with the same name and re-checking `SHOT_DIR=shots/check node scripts/screenshots.mjs`.

## Languages

The homepage has a Language menu with 17 languages (the same list as `/cheek-beat/`); English is the markup itself and the default. `src/i18n.js` swaps text on elements marked `data-i18n="key"` (plus `data-i18n-aria` / `data-i18n-alt`) using `public/i18n/<code>.json`, fetched only when that language is picked. `?lang=xx` sets the language for one visit; a choice in the menu is remembered in `localStorage["stelux-lang"]`, which `/cheek-beat/` and `404.html` read too. Arabic switches the page to right-to-left.

To change or add copy: edit the English in `index.html` (add `data-i18n` to new text), run `pnpm dev`, copy the output of `window.__steluxI18nSource()` from the browser console into `i18n/en.json`, update every `public/i18n/*.json`, then run `node scripts/i18n-check.mjs` (missing/extra keys, `{placeholders}`, line breaks). A key a language leaves out falls back to English.

The Arena page (`public/arena/`) is generated by the Arena publisher and has its own Chinese/English switch; its languages are changed in that project, not here.

## Product previews

The Arena card reads the same public, paper-only snapshot as the Arena page (`steluxai.github.io/arena-live/data/`) when it scrolls near the viewport and falls back to a plain link if that feed is unreachable. The Cheek Beat card loads the 15-second teaser only when visible (autoplay on wide screens, tap-to-play on phones and with Save-Data). The Michigan card is a labelled sample from a past daily report; Market Signal Pro and Lux are labelled concept previews.

## Deployment

**GitHub Pages (live at https://stelux.ai since 2026-09-03).** Every push to `main` runs `.github/workflows/deploy-pages.yml`, builds, and publishes to GitHub Pages. Custom domain `stelux.ai` is bound in the repository's Pages settings, the certificate is issued by GitHub and HTTPS is enforced; `www.stelux.ai` redirects to the apex. The previous tunnel-backed fashion product has been retired. This website continues to publish through GitHub Pages.

**Cloudflare Pages (ready).** `.github/workflows/deploy-cloudflare.yml` is a manual workflow. Add the repository secrets `CLOUDFLARE_API_TOKEN` (Pages:Edit + Account:Read) and `CLOUDFLARE_ACCOUNT_ID`, then run it from the Actions tab. Or deploy locally with `npx wrangler login && pnpm deploy`.
